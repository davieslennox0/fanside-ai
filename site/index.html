View live activity How it works

Live subgraph data

Every answer is backed by a real, current query against a real subgraph — search, schema, and execution all happen at request time.

Pay-per-question

x402 over HTTP: no accounts, no subscriptions. A 402 challenge is priced before your query ever runs, then settled instantly on Base.

Built for agents

A dedicated /api/agent/query endpoint lets other agents and apps call Fanside programmatically — it's infrastructure, not just a chat box.

Complexity-scaled pricing
